# literature

A mirror of a public domain novel, chunked for testing.

I keep needing long, clean prose to benchmark against and keep rebuilding the
same download. This is that download, committed so it stops being a step.

- Book: **Notes from Underground**
- Author: Fyodor Dostoevsky
- Source: Project Gutenberg (#600)
- Split: 4 files at paragraph breaks

## Layout

- `01-book-i.txt` — 81 KB
- `02-book-ii.txt` — 57 KB
- `03-book-iii.txt` — 45 KB
- `04-book-iiii.txt` — 51 KB

## Caveats

The text is a transcription of a pre-1928 translation, so spelling is period
accurate and sometimes inconsistent. That is the point — normalising it would
throw away exactly the noise I want to test against.

No licence file: public domain text, no restrictions attached.
